# 🌱 Primeiros Passos no Código

Uma trilha leve para aprender programação do zero: primeiro pensando como programadora, depois HTML, CSS e JavaScript.

📖 **Acesse a trilha:** https://mateus-lopes.github.io/trilha-programacao/

## Sobre este projeto

Esta trilha foi criada para ajudar a minha namorada a dar os primeiros passos na programação. Por isso, os exemplos falam de coisas que ela gosta: doces, salão de beleza, vôlei, academia e compras.

Se você também está começando, fique à vontade para usar!

## Rodando localmente

O site é feito com [Zensical](https://zensical.org/).

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt   # no Linux/Mac: .venv/bin/pip
.venv/Scripts/zensical serve
```

A cada push na `main`, o site é publicado automaticamente no GitHub Pages.
