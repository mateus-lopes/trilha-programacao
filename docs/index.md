# 🌱 Primeiros Passos no Código

Oi! Que bom ter você aqui. 💕

Esta é uma trilha para aprender a programar **do zero absoluto**. Não precisa saber nada antes: nem o que é código, nem inglês de computador, nem matemática difícil. A gente vai começar bem do começo, com calma, um passinho de cada vez.

## O que você vai criar

Ao longo da trilha, você vai construir coisas de verdade, com a sua cara:

- 💁‍♀️ Uma página **"Sobre mim"**, bonita e publicada na internet com um link só seu
- 🏐 Um **placar de vôlei** que funciona com botões
- 🏋️ Um **contador de séries** para a academia
- 🛍️ Um **carrinho de compras** que soma o total sozinho
- 🏆 E, no final, um **projeto escolhido por você**

## Como a trilha é organizada

A trilha é dividida em **módulos**, e cada módulo tem várias **lições** curtinhas (mais ou menos 1 hora cada, já contando o desafio).

| Módulo | O que você aprende |
|---|---|
| [**0 · Preparando o cantinho**](modulo0/index.md) | Deixar o computador pronto e entender como estudar por aqui |
| [**1 · Pensando como programadora**](modulo1/index.md) | O que é programar, **sem nenhum código** ainda |
| [**2 · HTML**](modulo2/index.md) | Criar páginas: o esqueleto de todo site |
| **3 · CSS** · *em breve* | Deixar as páginas bonitas: a maquiagem do site 💄 |
| **4 · Página no ar** · *em breve* | Publicar a sua página na internet |
| **5 · JavaScript** · *em breve* | Dar vida às páginas: botões, contas e decisões |
| **6 · Projeto final** · *em breve* | Juntar tudo num projeto seu |

## Por onde começar?

Pelo começo mesmo! 😊 Vá para o [**Módulo 0**](modulo0/index.md).

!!! tip "Uma coisa importante antes de tudo"
    **Não existe pressa aqui.** Você não está atrasada, não está competindo com ninguém e pode parar quando precisar. Aprender a programar é como treinar na academia: o que faz diferença é ir com constância, não ir com tudo num dia só.
