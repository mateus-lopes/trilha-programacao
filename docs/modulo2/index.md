# Módulo 2 · HTML: o esqueleto da página 🦴

Chegou a hora do primeiro código de verdade! 🎉

**HTML** é a língua das páginas de internet. Todo site que você já abriu, do Instagram à loja onde você compra roupa, tem HTML por baixo. Ele diz ao navegador **o que** é cada pedaço da página: isto é um título, isto é um parágrafo, isto é uma foto…

Neste módulo, você vai:

- Criar páginas do zero e abrir no navegador
- Escrever títulos, textos, listas, imagens, links e tabelas
- Construir, aos pouquinhos, a sua página **"Sobre mim"** 💁‍♀️

!!! tip "A página vai ficar sem graça (e tudo bem!)"
    Neste módulo, suas páginas vão ter letra preta, fundo branco e nenhum enfeite. **É assim mesmo.** O HTML é só o esqueleto. A maquiagem vem no Módulo 3, com o CSS. 💄 Primeiro a gente constrói, depois a gente deixa linda.
